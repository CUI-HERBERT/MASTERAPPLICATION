# 崔书赫的升学规划

个人升学规划网站的独立部署版。源码存放于 **GitHub 私有仓库**；网站由 Cloudflare Worker 运行，D1 保存跨设备数据，Cloudflare Access 控制私人登录。运行时不依赖 ChatGPT。

已有功能：

- 152 个保留项目，分别显示个人分档和随背景变化的建议。
- GPA 与科研证据情景比较；逐项目列出缺口、补齐目标及有条件的提档判断。
- 24 条初始经历：论文／稿件 8、竞赛 1、实习 2、奖项／入选 7、候选推荐人 6；可新增、修改和删除。
- 私人云端同步、本机缓存、收藏、申请进度、行动项和 JSON 备份。

建议档位是可解释的规划规则，不是统计录取概率。官方门槛、辅助换算与个人目标分开显示；更新背景不会自动刷新学校政策。现有项目资料保留各自的核对日期。

## 本地检查

使用 Node.js 22 或更新版本：

```sh
npm ci
npm test
npm run build
npm run preview
```

预览地址由命令输出。本机预览的云端 API 返回 401，仅使用本机保存；正式部署版要求有效的 Cloudflare Access 身份。GitHub Actions 只运行检查与构建，不自动发布。

## 独立部署与数据迁移

按 [部署与迁移说明](DEPLOYMENT.md) 配置新 D1、私人登录和部署。`wrangler.example.jsonc` 是模板；真实配置 `wrangler.jsonc` 不进入 Git。

私有仓库并不自动使发布的网站私有。此仓库含个人经历资料，不应直接作为公开 GitHub Pages 网站发布。独立版 Worker 对网页、个人经历资源和 API 都校验登录身份，配置未完成时拒绝访问。

初始经历 JSON 不是原网站的最新云端快照。迁移需要从原网站“导出我的备份”，再在新网站导入，才能带上之后的修改、收藏和进度。迁移验证完成前保留原网站。

## 代码位置

- `web/`：网页、保留项目、初始经历及规划规则。
- `worker/`：登录验证和带版本冲突保护的云端状态 API。
- `drizzle/`：D1 表结构迁移。
- `scripts/build.mjs`：构建独立 Worker；`dist/` 为生成文件。
- `tests/`：规则边界、经历迁移、云端保存和身份验证测试。

登录密钥、云端备份和本机状态不应提交至仓库。个人档案的来源与未确认事项见 `audit/portfolio-evidence.md`。
